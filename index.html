01 / SOFTWARE NATIVOSonic RouteEXPANDIR +
Problema
Controlar volume, silêncio e saída de áudio por aplicação no macOS.
Restrições
Protótipo para macOS 26 ou posterior; captura de áudio exige consentimento. Compatibilidade e latência ainda precisam de testes adicionais.
Arquitetura e decisões
Process taps do Core Audio alimentam um buffer e um mixer; serviços isolados da interface permitem testar regras sem dispositivos físicos.
Resultado e aprendizado
O repositório documenta descoberta de processos, controles e preferências. O projeto evidencia a importância de validar áudio real e permissões além dos testes unitários.

02 / PRODUTO E CLOUDEpisodicEXPANDIR +
Problema
Acompanhar séries, episódios assistidos e próximos lançamentos em uma biblioteca pessoal.
Restrições
O produto depende de autenticação, catálogo externo e persistência do progresso.
Arquitetura e decisões
Interface Next.js conversa com funções Rust no AWS Lambda, API Gateway e DynamoDB; a infraestrutura está em Terraform.
Resultado e aprendizado
A interface reúne catálogo, biblioteca e histórico. O projeto demonstra como dividir responsabilidades entre produto, API e infraestrutura.

03 / INGESTÃO DE DADOSDota Collection ToolEXPANDIR +
Problema
Capturar e consultar o estado enviado pelo jogo durante partidas.
Restrições
A coleta depende da configuração de Game State Integration e de receber eventos locais do jogo.
Arquitetura e decisões
Um serviço HTTP recebe os dados; módulos Rust separam domínio, rede, persistência SQLite e CLI. Há também interface desktop.
Resultado e aprendizado
O projeto oferece coleta, logs e exportação. A separação entre ingestão e armazenamento facilita compreender e evoluir o processamento dos eventos.
